# Avanki – Claims TPA

App xử lý DPBT / Theo dõi HS TPA chạy trên trình duyệt (Chrome/Edge).

- Link app: https://avanki188.github.io/avanki-tpa/
- Repo chỉ chứa code. **Dữ liệu hồ sơ, DATA hợp đồng, Cài đặt nằm trong thư mục OneDrive của người dùng** (các file `dpbt-*.json`), không đưa lên đây.
- `version.json`: số phiên bản mới nhất, app dùng để báo "Có bản mới".
